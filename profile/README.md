# Ahmed Elmi Research

**Open research into AI-agent security, led by Ahmed Elmi.**

I am developing my expertise through small, reproducible experiments and transparent research notes. My first focus is **safe task resumption**: how an agent should remain within its current permissions after an interruption.

## Start here

[Explore the AI Agent Security research repository](https://github.com/ahmed-elmi-research/ahmed-elmi-agent-security)

The repository contains the research plan, proposed experiments, learning journal and contribution guidelines. This work is at an early stage: the initial setup and design review are complete; experimental results have not yet been established.

## How the research is conducted

- State a question and a prediction before testing.
- Use controlled local experiments with synthetic data.
- Preserve reproduction steps, observations and limitations.
- Publish unsuccessful trials as well as successful ones.
- Disclose AI assistance; distinguish review feedback from evidence.

Codex supports setup and tutoring; Claude Code contributes independent review. Ahmed is responsible for the research decisions and explanations.

## Participate
